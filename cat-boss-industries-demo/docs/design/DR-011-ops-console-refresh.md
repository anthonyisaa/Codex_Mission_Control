# DR-011: Operations Console UI Refresh

## Objective
Move from plain list view to high-fidelity operations console with stronger visual hierarchy.

## Design direction
- Sidebar navigation + top command area.
- Card-based board with severity badges.
- Warm paper-like palette with clear state contrast.
- Responsive behavior for mobile and desktop.

## Must keep
- Existing data semantics and API behavior.
- Filter links by status and severity.
- Accessibility basics (focus visibility and readable contrast).
